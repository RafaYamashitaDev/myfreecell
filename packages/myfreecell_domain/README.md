# myfreecell_domain

`myfreecell_domain` is a private, unpublished pure-Dart package reserved for MyFreecell's deterministic gameplay domain. It has no Flutter dependency. It currently exposes only the foundational card vocabulary: suits, ranks, card colors, and cards.

Its repository boundary is defined by [ADR-03](../../docs/architecture/adr-03-repository-structure-and-domain-isolation.md).
